# 商家端

商家端使用 Vue 3 + TypeScript + Element Plus 开发，默认端口 `5173`。它是商家处理万象商城订单售后、客服会话、评价治理和经营分析的工作台。

## 当前功能

- 商家一级账号登录。
- 绑定/解绑万象商城商家二级账号。
- 未绑定店铺时限制进入业务页面。
- 工作台展示账号信息、关键指标、服务动态和待处理事项。
- 售后处理支持待审核、处理中、已结束、争议订单分类。
- 退货退款支持审核、用户填写退货快递单号、商家确认收货后同意退款。
- 仅退款支持商家同意或拒绝，拒绝时填写原因。
- 消费者二次售后争议后，商家可提交二次举证图片和说明。
- 实时客服支持 AI/人工会话、商家回复、结束人工服务、订单详情查看。
- 评价分析支持评价详情、商家异议、AI 生成情感、分析摘要和处理建议。
- 知识库支持常见问题、售后政策和详细内容查看。
- 统计分析展示订单、售后、评价等维度的经营数据。

## 启动方式

```powershell
cd "D:\Software Engineering Training\ecommerce-after-sale-system\frontend\merchant-web"
npm install
npm run dev
```

访问：`http://localhost:5173`

## 依赖服务

- 后端：`http://localhost:8080`
- AI 服务：`http://localhost:9000`
- MySQL：存储账号、绑定关系、订单、售后、评价、聊天等真实数据

## AI 评价分析

评价详情中的“AI 分析”按钮会调用 AI 服务，根据产品质量评价、商家服务评价、星级、商品、商家和订单信息生成：

- 情感
- 分析摘要
- 处理建议

点击前这三项不显示；点击后才展示 AI 生成结果。
