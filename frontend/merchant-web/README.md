# 商家端

商家端使用 Vue 3 + TypeScript + Element Plus 开发，默认端口 `5173`。它是商家处理平台店铺绑定、订单售后、客服会话、评价治理、知识库和经营分析的工作台。

## 当前功能

- 商家一级账号登录：支持手机号+密码登录。
- 店铺绑定：支持绑定/解绑万象商城、悦购集市商家二级账号；二级账号只能绑定到所属平台，不能跨平台绑定。
- 账号信息：导航栏左下角展示头像，点击可查看账号信息或退出登录；账号信息页可编辑头像和昵称。
- 客服身份确认：每个商家一级账号默认有客服 A/B/C/D，客服秘钥保存在数据库中，输入秘钥后切换当前客服身份。
- 操作权限：售后处理、争议订单、评价异议、知识库新增/删除和人工客服发消息都需要先确认客服身份。
- 操作日志：记录客服在什么时间进行了什么操作，切换客服身份不会清空日志。
- 工作台：展示账号信息、关键指标、服务动态邮件、待处理事项和统计入口。
- 售后处理：支持未申请、售后中、处理中、已结束、争议订单分类。
- 退货退款：支持审核、消费者填写退货快递单号、商家确认收货并同意退款。
- 仅退款：商家可同意或拒绝，拒绝时填写原因；消费者可申请平台介入。
- 争议订单：商家可进行二次举证，提交文字和图片，由平台管理员最终处理。
- 实时客服：支持 AI/人工会话、商家真人回复、结束人工服务、订单详情查看和切换订单。
- 服务动态：以邮件形式展示新售后、新评价、评价异议审核结果等变动，未读显示红点。
- 评价分析：查看评价详情、对评价提出异议、单条 AI 分析、一级账号整体 AI 分析和单个二级商家 AI 分析。
- 知识库：支持常见问题、售后政策、知识文章；新增时可上传文本或文件，由 AI 抽取内容后确认写入。
- 规则查看：查看平台售后规则、触发条件和执行动作。
- 统计分析：展示订单、售后、评价等维度的经营数据。

## 启动方式

```powershell
cd "D:\Software Engineering Training\ecommerce-after-sale-system\frontend\merchant-web"
npm install
npm run dev
```

访问：`http://localhost:5173`

也可在项目根目录使用：

```powershell
.\scripts\dev-start.ps1
```

## 依赖服务

- 后端：`http://localhost:8080`
- AI 服务：`http://localhost:9000`
- MySQL：存储账号、绑定关系、商品、订单、售后、争议、评价、聊天、知识库、规则和操作日志

## AI 评价分析

评价详情中的“AI 分析”按钮会调用 AI 服务，根据商品质量评价、商家服务评价、星级、商品、商家和订单信息生成：

- 情感
- 分析摘要
- 处理建议

“查看店铺评价 AI 分析”支持两种范围：

- 一级账号整体：汇总当前商家一级账号下全部已绑定二级商家的未删除评价。
- 单个二级商家：选择具体二级商家，只分析该商家的未删除评价。

两种范围都会生成整体情感倾向、评价摘要和处理建议。
