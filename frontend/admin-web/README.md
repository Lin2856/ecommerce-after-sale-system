# 平台管理员端

管理员端使用 Vue 3 + TypeScript + Element Plus 开发，默认端口 `5175`。它用于平台侧运营、治理、争议处理、配置维护和系统监控。

## 当前功能

- 管理员登录：四个管理员账号通过 8 位秘钥登录，并展示不同管理员头像。
- 系统概览：展示消费者、商家、订单、售后、评价、知识库、规则等真实统计数据。
- 外部平台：展示万象商城、悦购集市等平台接入状态和配置。
- 同步监控：展示订单、售后、评价等数据库同步概况。
- 消费者管理：查看消费者一级账号、头像、昵称、手机号及绑定的二级平台账号。
- 商家管理：查看商家一级账号、头像、昵称、手机号、绑定店铺数和二级商家账号。
- 账号治理：支持封禁/解封消费者或商家一级账号，可选择 1 天、3 天、7 天、1 个月、半年、1 年、10 年或永久。
- 评价分析：查看评价数据、风险等级、已删除评价、评价详情和 AI 分析结果。
- 评价异议审核：审核商家提出的评价异议，同意后删除评价，不同意则保留原风险等级。
- 争议订单处理：处理消费者二次售后争议，查看双方举证、商品详情，并裁定全额/部分退款或支持商家。
- 规则配置：维护售后规则、触发条件和执行动作。
- 知识库：支持手动新增，也支持上传文本或文件后由 AI 自动识别问题、分类和答案，确认后写入。
- AI 配置：查看 AI 服务状态，编辑 API Key，保存后直接作用于真实 AI 对话。
- 操作日志：记录管理员封禁、解封、争议订单处理、异议评价处理、规则配置和知识库新增等操作。

## 启动方式

```powershell
cd "D:\Software Engineering Training\ecommerce-after-sale-system\frontend\admin-web"
npm install
npm run dev
```

访问：`http://localhost:5175`

也可在项目根目录使用：

```powershell
.\scripts\dev-start.ps1
```

## 依赖服务

- 后端：`http://localhost:8080`
- AI 服务：`http://localhost:9000`
- MySQL：系统统计、账号、评价、争议、知识库、规则和日志数据来源

如果 AI 服务未启动，API Key 保存、AI 状态检查、评价 AI 分析、知识库智能解析会失败。

## 安全说明

- 管理员端只负责展示和提交 API Key，真实密钥写入本地 `ai-service/.env`。
- `ai-service/.env` 不会提交到 GitHub。
- 管理员操作应写入操作日志，便于后续审计。
