# 消费者微信小程序

消费者端使用微信小程序原生框架开发，用于演示消费者在融合电商平台售后系统中的平台绑定、订单查询、售后申请、客服咨询和评价流程。

## 当前功能

- 登录：支持手机号+密码登录。
- 头像资料：可在个人资料中维护头像和昵称。
- 平台绑定：支持绑定/解绑万象商城、悦购集市消费者二级账号，同一个二级账号只能被一个一级账号绑定。
- 订单查看：按平台、账号、店铺分组展示订单；支持一个商品对应多个订单。
- 商品详情：展示商品图片、描述、价格、规格和售后政策。
- 售后申请：支持仅退款、退货退款、价保等申请类型，支持文字说明和图片凭证。
- 退货退款：商家同意后消费者填写退货快递单号，提交后同步到商家端。
- 二次售后争议：商家拒绝后，消费者可申请平台介入，并提交文字和图片举证；每个订单只能申请一次平台介入。
- 在线客服：支持 AI 回复、AI 不确定时引导转人工、人工客服回复、订单详情查看和切换订单。
- 评价提交：每个订单只能评价一次，即使评价被管理员删除，也不允许重复评价；评价分为商品质量评价和商家服务评价。
- 个人中心：支持地址管理、绑定账号查看、退出登录和注销账号。

## 打开方式

使用微信开发者工具导入：

```text
frontend/consumer-miniapp
```

运行前请确保：

- 后端服务已启动：`http://localhost:8080`
- AI 服务已启动：`http://localhost:9000`
- MySQL 中已执行 `database/init.sql`、`database/seed.sql` 及需要的补丁脚本

## 数据说明

消费者端核心数据均通过后端接口读取和写入 MySQL，包括账号、绑定关系、商品、订单、售后、争议、评价、聊天记录、头像和昵称。

## 常见问题

- 登录后没有订单：检查一级账号是否绑定了对应平台二级账号。
- AI 不回复：检查 `http://localhost:9000/health`、AI API Key 和后端是否能访问 AI 服务。
- 售后或评价状态不同步：刷新页面，并确认后端服务仍在运行。
