# 消费者微信小程序

消费者端使用微信小程序原生框架开发，用于演示消费者在融合电商平台售后系统中的订单查询、售后申请、客服咨询和评价流程。

## 当前功能

- 一级账号手机号登录。
- 绑定/解绑万象商城消费者二级账号。
- 查看按平台、账号、店铺分组的订单。
- 查看商品详情、商品图片、价格、描述和售后政策。
- 发起仅退款、退货退款、价保等售后申请。
- 填写申请原因并上传凭证图片。
- 修改售后信息、取消售后申请。
- 商家同意退货退款后填写退货快递单号。
- 商家拒绝后可发起二次售后争议，并提交文字和图片举证。
- 在线客服支持 AI 回复、转人工、商家真人回复和订单切换。
- 对订单进行一次评价，评价分为商品质量评价和商家服务评价。
- 个人中心支持头像、昵称、地址新增删除、退出登录和注销账号。

## 打开方式

使用微信开发者工具导入：

```text
frontend/consumer-miniapp
```

运行前请确保：

- 后端服务已启动：`http://localhost:8080`
- AI 服务已启动：`http://localhost:9000`
- MySQL 中已执行 `database/init.sql` 和 `database/seed.sql`

## 数据说明

消费者端不再使用纯本地演示数据。订单、售后、评价、绑定关系、聊天记录等核心数据都通过后端接口读取和写入 MySQL。

## 常见问题

- 如果登录后没有订单，检查该一级账号是否已绑定万象商城二级账号。
- 如果 AI 不回复，检查 AI 服务 `http://localhost:9000/health` 和 API Key 配置。
- 如果售后或评价状态不同步，刷新页面并确认后端服务仍在运行。
